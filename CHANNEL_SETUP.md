# QUANTSIGNAL AI — Telegram-канал: настройка автопостов

Документ описывает, как включить **автопубликации** премиальных аналитических постов
QUANTSIGNAL AI в Telegram-канал. **По умолчанию публикации выключены** — эндпоинт
возвращает только превью.

## 1. Создайте канал в Telegram

1. Создайте публичный (или приватный) канал, например `@QuantsignalAI` (имя по
   вашему усмотрению).
2. Зайдите в **настройки канала → Администраторы**.
3. Добавьте бота `@QUANTSIGNAL_AI_BOT` (или вашего бота, токен которого вы
   используете) в администраторы канала и **выдайте право «Публикация
   сообщений»**. Другие права не нужны.

## 2. Найдите идентификатор канала

- Для **публичного** канала используйте `@username` (например, `@QuantsignalAI`).
- Для **приватного** канала используйте числовой `chat_id` вида `-100xxxxxxxxxx`.
  Узнать его проще всего так: добавьте бота, отправьте в канал любое
  сообщение, и затем выполните
  `https://api.telegram.org/bot<TOKEN>/getUpdates` — в ответе будет `chat.id`.

## 3. Настройте переменные окружения в Vercel

В **Project Settings → Environment Variables** добавьте:

| Имя                              | Значение                          | Обязательно |
| -------------------------------- | --------------------------------- | ----------- |
| `TELEGRAM_BOT_TOKEN`             | токен вашего бота                 | да          |
| `QSI_TELEGRAM_CHANNEL_ID`        | `@username` или `-100xxxxxxxxxx`  | да          |
| `QSI_CHANNEL_POSTING_ENABLED`    | `1` (включить реальные посты)     | да, для боя |
| `QSI_CRON_SECRET`                | произвольный длинный секрет       | желательно  |

> **Важно:** пока `QSI_CHANNEL_POSTING_ENABLED` ≠ `"1"`, эндпоинт всегда
> возвращает JSON-превью и **не** обращается к Telegram. Это безопасный
> режим по умолчанию.

> **Совместимость:** также читаются `BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`,
> `CRON_SECRET` — если у вас уже используются эти имена.

## 4. Расписание (внешний шедулер)

> **Важно про Vercel Hobby.** На тарифе Vercel Hobby крон-задачи разрешены
> **только раз в сутки**. Поэтому блок `crons` из `vercel.json` **удалён**:
> иначе деплой падает с ошибкой `Hobby accounts are limited to daily cron jobs`.
> Эндпоинт `/api/channel/post` остаётся полностью рабочим и доступным как
> обычная HTTP-функция — его можно дёргать вручную или из внешнего шедулера.

Для **трёх постов в сутки** (Магадан, UTC+11) используйте один из вариантов:

| UTC    | Магадан (UTC+11) |
| ------ | ---------------- |
| 22:00  | 09:00 (утро)     |
| 04:00  | 15:00 (день)     |
| 10:00  | 21:00 (вечер)    |

Варианты внешнего шедулера:

- **Perplexity Recurring Tasks** (или любой другой ассистент с recurring-задачами):
  настройте три повторяющиеся задачи, которые делают GET-запрос на
  `https://<ваш-домен>/api/channel/post` с заголовком
  `Authorization: Bearer <QSI_CRON_SECRET>` в 22:00 / 04:00 / 10:00 UTC.
- **GitHub Actions** с тремя `schedule:` cron-выражениями, выполняющими `curl`.
- **cron-job.org**, **EasyCron**, **Upstash QStash**, **Cloudflare Worker
  `scheduled`-trigger** — любой внешний планировщик, умеющий вызывать HTTP по
  расписанию.
- **Vercel Pro** — на платном тарифе можно вернуть блок `crons` со
  схемой `0 22,4,10 * * *` обратно в `vercel.json` и пользоваться нативным
  Vercel Cron.

Если `QSI_CHANNEL_POSTING_ENABLED ≠ 1` или нет токена/канала — эндпоинт
**молча отдаст превью** и **ничего не опубликует**, независимо от того,
кто его вызывает.

## 5. Проверка перед боем

1. Откройте `https://<ваш-домен>/api/channel/post?preview=1` — должны
   вернуться JSON-превью, текст поста и base64-SVG картинки.
2. Сохраните base64 в файл и откройте — это и будет картинка поста.
3. Только после визуальной проверки выставьте `QSI_CHANNEL_POSTING_ENABLED=1`
   и сделайте редеплой.
4. Дождитесь срабатывания внешнего шедулера **или** выполните вручную:
   ```
   curl -H "Authorization: Bearer <QSI_CRON_SECRET>" https://<ваш-домен>/api/channel/post
   ```
   В ответе будет `{"ok": true, "mode": "posted", "message_id": ...}`.

## 6. Что публикуется

- 🛰 Заголовок «QUANTSIGNAL AI · Сводка рынка» + краткий хедлайн.
- Настроение рынка (Бычий / Медвежий / Нейтральный) и средняя динамика.
- Котировки BTC / ETH / SOL / TON / DOGE: цена + 24h%.
- Короткий аналитический комментарий в премиальном стиле (RU).
- Дисклеймер «Не финансовая рекомендация. Управляйте риском.»
- Брендированная картинка (Q-метка, фирменный синий, тёмный фон).

Источник котировок: Bybit V5 → Coinbase Exchange → Kraken (фоллбэк). Если все
провайдеры недоступны для какой-то монеты — в посте честно отображается «—».

## 7. Безопасность

- Реальный пост возможен только при одновременном выполнении трёх условий
  (`QSI_CHANNEL_POSTING_ENABLED=1`, токен и `chat_id` заданы).
- Если установлен `QSI_CRON_SECRET`, любой публичный вызов **без** валидного
  секрета на боевую отправку получит `401 unauthorized`. Превью (`?preview=1`)
  работает без секрета.
- Токен бота не логируется и не возвращается в ответе.
- Текст и данные котировок экранируются перед вставкой в HTML и SVG.
