Предупреждения

Публикация в канал

Публикация в канал @QUANTSIGNAL_AI выполняется только через секретный эндпоинт /api/content/publish. Этот UI не отправляет запросы публикации, чтобы не светить секрет в браузере.

Чтобы опубликовать с локальной машины оператора (когда включены QSI_CHANNEL_POSTING_ENABLED=1, TELEGRAM_BOT_TOKEN, QSI_TELEGRAM_CHANNEL_ID и задан QSI_CRON_SECRET):

curl -X POST "https://quantsignal-miniapp.vercel.app/api/content/publish?type=market_update" \
  -H "Authorization: Bearer $QSI_CRON_SECRET"

Сначала всегда проверяйте превью этой страницей или ?dry_run=1 в запросе.
